# LearnLang (LangLab)

Fullstack проект, представляющий из себя веб-приложение для изучения английского языка. Функционал предоставляет словарь с возможностью сохранять и изучать слова, просматривать уроки по грамматике и вокабуляру, проходить тесты для закрепления знаний с сохранением прогресса пользователя.

## Backend
- ASP.NET Core
- PostgreSQL

## Frontend
- JavaScript
- HTML/CSS

#DevOps
- Docker Compose (для PostgreSQL)
